# Bloquons l’extrême droite et ses relais

Une checklist personnelle pour retrouver des comptes sur les réseaux sociaux et suivre ceux que vous avez bloqués.

## Utilisation

Ouvrez la page du site. Pour chaque entrée, utilisez les icônes de réseaux sociaux pour rechercher le compte correspondant, puis cochez la case lorsque vous avez terminé. Les liens ouvrent des recherches : vérifiez qu’il s’agit bien du compte voulu avant d’agir.

## Sauvegarde de la progression

La progression est enregistrée automatiquement dans le navigateur utilisé. Elle n’est pas partagée avec les autres personnes qui visitent le site.

- **Exporter** télécharge une copie de la progression au format JSON.
- **Importer** restaure une progression depuis un fichier JSON.
- La progression peut ainsi être transférée vers un autre navigateur ou appareil.

## Publier avec GitHub Pages

1. Placez le fichier HTML à la racine du dépôt et nommez-le `index.html`.
2. Dans GitHub, ouvrez **Settings → Pages**.
3. Activez la publication depuis la branche `main` et le dossier `/ (root)`.
4. Une fois le site publié, partagez l’adresse indiquée dans les paramètres **Pages**.

## À propos de la liste

La liste est non exhaustive. Les affiliations et fonctions peuvent évoluer ; les entrées et les résultats de recherche sont à vérifier. Le projet fournit des recherches pour aider à retrouver des comptes, sans garantir l’identité d’un compte ni recommander une action particulière.
